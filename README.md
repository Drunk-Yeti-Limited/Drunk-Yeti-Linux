# Drunk Yeti PlaySpace Linux

Public distribution and installation home for Drunk Yeti Linux: a useful desktop with an optional game world, desktop companion and creative tools.

**Status: development preview. No ISO has been built, boot-tested or published here yet.** Do not interpret this repository as a downloadable operating-system release.

Future verified images, SHA256SUMS, build inventories, release notes and known issues will be attached to GitHub Releases. Application source remains in the private development repository.

See [installation and VM guidance](INSTALLATION.md) and [release acceptance](RELEASE-CHECKLIST.md).
