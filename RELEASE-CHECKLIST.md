# Release acceptance

An ISO release must include its exact source revision, dependency/package inventories, build log, checksums and known issues. Upload large images as release assets, not Git blobs. Do not label an image stable merely because the build command succeeds.

Required acceptance: BIOS and UEFI boot; normal-user browser sandbox; account sign-in/sign-out and keyring; purchased theme revocation and account switching; all bundled apps; project save/reopen; every Linux maker export; exported game startup; package tools; network/audio/graphics/input; shutdown; display scaling; documented persistence behavior. Public-facing statements must distinguish implemented, fixture-tested and hardware-verified features.

Snow and stars are optional. Companion sleep never locks the user's ordinary desktop. Account purchases use authoritative backend ownership; local theme preferences are cosmetic, not authentication or billing authority.
