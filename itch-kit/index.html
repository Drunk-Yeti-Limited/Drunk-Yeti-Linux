Get the live image

Download. Assemble. Try it.

  1. Open the GitHub release. Download both .part01 and .part02 files, plus Assemble-ISO.command.
  2. Keep all three in one folder. Allow at least 8 GB of free space. Do not mix files from different releases.
  3. Assemble on macOS or Linux. Open Terminal in that folder and run the command below. The script verifies both parts and the complete ISO.
  4. Boot the verified ISO in a VM. Start with 4 GB RAM, 2 virtual CPU cores, and BIOS firmware. Select “Live system (amd64)” and press Enter.
bash Assemble-ISO.command

Windows: follow the Command Prompt assembly steps in READ-ME.txt on the release page. The individual parts are not bootable.

Before you begin

A preview, with clear limits.

No installer or configured persistence. This is a live development image. Save important work outside the live session before shutting down.
What has been tested?

The ISO compiled successfully and reached PlaySpace in a BIOS VM. UEFI, Secure Boot, physical hardware, online account flows, and full application acceptance remain pending. The boot menu still uses Debian artwork.

Can I use an Apple Silicon Mac?

This is an x86_64 image. Use x86_64 emulation in UTM, rather than ARM virtualization. Performance on a Mac has not been measured.

Is this a browser game or the finished release?

No. This upload is a download landing page for a Linux live ISO. The operating system is a development preview, with some creative-app launchers and companion integrations still unfinished.
